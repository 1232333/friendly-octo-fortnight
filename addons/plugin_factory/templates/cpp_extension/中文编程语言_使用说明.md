# 中文游戏编程语言使用说明

## 在游戏节点上执行

1. 先编译并加载 Android ARM64 GDExtension。
2. 在 Godot 场景树中选中要控制的节点。
3. 打开“中文编程语言”面板并输入：

```text
当 游戏开始:
    自身.position = Vector2(100, 100)
    打印("开始")
结束

当 每帧(delta):
    如果 输入.正在按下("向右"):
        自身.position.x += 200 * delta
    结束
结束
```

4. 点击“编译并绑定到选中节点”。
5. 编译器生成的 GDScript 会先通过 Godot 脚本检查，然后绑定到所选节点。保存场景并运行游戏。

输入动作（例如“向右”）需要先在项目设置的 Input Map 中创建。

## 当前实现边界

- C++ 编译器将中文源码转换为 GDScript；Godot 负责最终检查和执行。
- 支持的生命周期事件：游戏开始、每帧、物理帧、输入事件、退出场景。
- 当前语法仍是行级 MVP，不是完整 AST、类型系统或独立虚拟机。
- 更新 C++ 编译器后，必须重新构建 Android ARM64 动态库；仅更新 GDScript 插件文件不会更新编译器。
- Android 真机执行仍须在实际项目中验证。
