# 中文游戏编程语言使用说明

## 当前实现

本插件使用独立的中文编译器和 C++ 虚拟机，不是 GDScript 翻译器。

```text
中文源码（.zh）
  → UTF-8 Lexer / Parser
  → AST 与基础静态类型检查
  → ZHBC v2 字节码
  → C++ 中文虚拟机
  → Godot Host API
```

编译器和虚拟机有不依赖 Godot 的 C++ 测试。插件不会把用户编写的中文程序转换成或生成 GDScript。

## 在 Godot 中使用

1. 将插件目录放在项目的 `res://addons/chinese_programming_language/`。
2. 将 Android ARM64 原生库放在 `res://addons/chinese_programming_language/bin/android/`，并确认项目根目录的 GDExtension 描述文件指向正确的动态库。
3. 在“项目 → 项目设置 → 插件”中启用“中文编程语言”。
4. 打开编辑器主屏幕中的“中文编程语言”页面，编写中文程序。
5. 点击“编译并运行（原生 VM）”。源码保存为 `res://scripts/hello.zh`，编译产物保存为 `res://generated/hello.zhbc`。

如果提示“原生中文 VM 尚未加载”，说明 GDExtension 尚未成功加载；先检查动态库路径、ABI 和 Godot 版本。Linux CI 构建成功不等于 Android ARM64 真机加载已经验证。

## 核心语法示例

```text
变量 分数: 整数 = 80
打印("分数：", 分数)
如果 分数 >= 60:
    打印("及格")
否则:
    打印("不及格")
结束
```

函数与递归：

```text
函数 阶乘(n: 整数) -> 整数:
    如果 n <= 1:
        返回 1
    否则:
        返回 n * 阶乘(n - 1)
    结束
结束

打印(阶乘(6))
```

## Godot 场景事件

将原生 `ChineseProgram` 节点添加到场景，并在检查器的 `bytecode_path` 属性中指定 `.zhbc` 文件。节点会在进入场景时读取字节码，并调度中文事件：

```text
当 游戏开始:
    打印("游戏开始")
结束

当 每帧(delta):
    打印(delta)
结束
```

`游戏开始` 由 C++ `_ready` 生命周期回调触发，`每帧(delta)` 由 C++ `_process` 回调触发。节点路径从当前场景根节点解析。

## 当前 Godot Host API

- `获取节点("UI/按钮")`：从当前场景根节点查找节点。
- `设置可见(节点, 假)`：设置 CanvasItem 可见状态。
- `设置位置(节点, 320, 180)`：设置 Node2D 或 Control 的位置。
- `设置属性(节点, "text", "开始游戏")`：设置对象属性。
- `读取属性(节点, "text")`：读取布尔、整数、浮点或字符串属性。

示例：

```text
变量 按钮 = 获取节点("UI/按钮")
设置可见(按钮, 真)
设置位置(按钮, 320, 180)
设置属性(按钮, "text", "开始游戏")
打印("按钮已设置")
```

节点句柄只在一次同步 VM 执行期间有效。信号连接、异步调用、完整 Variant 类型和对象生命周期托管尚未实现，不应视为当前已支持功能。
