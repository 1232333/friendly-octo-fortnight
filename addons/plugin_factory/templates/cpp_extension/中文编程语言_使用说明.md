# 中文游戏编程语言使用说明

## 当前版本状态

当前仓库中的旧原型仍然是“中文源码 → GDScript”的转译实现。它能验证编辑器接入和部分中文语法，但不是项目最终目标，也不应被描述为独立编译语言。

项目正在转向原生编译器与独立字节码虚拟机：
中文源码(.zh) → AST/语义分析 → 自有字节码(.zhbc) → 中文 VM → Godot Host API

## 正式版本的运行方式（目标）

1. 在中文语言编辑器中编写 .zh 源码。
2. 编译器生成独立的 .zhbc 文件。
3. 字节码验证器检查文件版本、指令和类型/寄存器边界。
4. 中文 VM 加载并执行字节码。
5. VM 通过 Godot Host API 控制节点、输入、信号、物理和 UI。
6. 输出、错误、调用栈和变量监视由 VM 调试接口提供。

## 验收原则

- 不生成 GDScript 作为用户程序。
- 编译器和 VM 必须有不依赖 Godot 的 C++ 单元测试。
- 编译产物必须是自有字节码格式。
- 相同字节码在独立测试运行器与 Godot 插件中执行结果一致。
- 未完成 VM 的功能不得在 UI 中标记为已支持。
