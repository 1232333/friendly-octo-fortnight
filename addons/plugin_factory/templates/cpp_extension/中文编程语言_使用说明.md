# 中文编程原型使用说明

当前编译器由 C++ 实现，并通过 GDExtension 的 `ChineseLanguage` 类提供给 Godot。

## 编译器调用

在 Godot 项目中先完成 C++ 扩展编译并确认扩展可加载：

```gdscript
var compiler := ChineseLanguage.new()
var result: Dictionary = compiler.compile("变量 分数 = 80\n打印(分数)\n")
if result.ok:
    print(result.code)
else:
    push_error(result.error)
```

## 当前支持语法

```text
变量 名称 = 表达式
打印(表达式)
如果 条件:
    ...
否则:
    ...
结束
循环 条件:
    ...
结束
函数 名称(参数1, 参数2):
    ...
    返回 表达式
结束
```

逻辑关键字：`真`、`假`、`空`、`并且`、`或者`、`不`。

中文标识符会被确定性转换成内部 ASCII 名称，避免目标 GDScript 编译器对 Unicode 标识符的兼容性差异。字符串内容仍保持 UTF-8 原样。

## 当前限制
- 当前为行级语法原型，缩进由 `结束` 关键字控制。
- 还没有完整 AST、类型检查、作用域分析、模块系统和调试行映射。
- 编译结果是 GDScript 源码；要执行还需写入 .gd 文件并由 Godot 加载。
- 这版没有声称已在 Android 真机运行；需先完成 Termux ARM64 编译并在 Godot 4.7.2 Android 编辑器加载验证。
