# 中文编程语言（C++ 实现）设计草案

## 目标
开发一门面向 Godot 的中文编程语言。编译器核心使用 C++，通过 GDExtension 暴露给 Godot 编辑器；第一阶段将中文源码转换为 Godot GDScript，再由 Godot 执行。后续再评估独立字节码与运行时，避免一开始就重造整个引擎。

## 第一阶段语法（MVP）
```text
变量 分数 = 80
打印(分数)

如果 分数 >= 60:
    打印("及格")
否则:
    打印("不及格")
结束

函数 问候(名字):
    打印("你好")
结束
```

关键字：
- `变量`：声明变量
- `打印`：输出
- `如果` / `否则` / `结束`：条件分支
- `循环` / `结束`：循环
- `函数` / `返回`：函数和返回值
- `真` / `假` / `空`：布尔值和空值
- `并且` / `或者` / `不`：逻辑运算

## 编译架构
1. UTF-8 词法分析：识别中文关键字、中文标识符、数字、字符串、运算符。
2. 语法分析：逐步从行级 MVP 扩展为 AST，提供准确行列错误。
3. 名称解析：把中文变量名稳定映射为 GDScript 可用的内部标识符。
4. 代码生成：输出 GDScript，保留源码行映射。
5. Godot 集成：通过 `ChineseLanguage.compile(source)` 返回编译结果；编辑器插件后续加入源码编辑、错误列表、运行与调试。
6. 后续方向：类型系统、模块/导入、节点与场景 API 中文包装、调试信息和独立字节码。

## 当前实现范围
当前是 C++ 编写的行级编译器原型，已支持变量、打印、条件、否则、循环、函数、返回、逻辑关键字和中文标识符内部映射。它是第一步，不代表完整语言或完整 IDE。复杂表达式的语法校验、作用域、类型系统和调试映射将在后续阶段实现。
