# 中文游戏编程语言设计

## 产品目标

中文脚本必须真正参与游戏运行，而不是只在编辑器里翻译或展示代码。第一阶段使用 C++ 编译器将中文源码转换为 GDScript，由 Godot 原生运行时执行；编译后可将脚本绑定到场景中当前选中的节点。

## 第一阶段语言

```text
当 游戏开始:
    自身.position = Vector2(100, 100)
    打印("角色已生成")
结束

当 每帧(delta):
    如果 输入.正在按下("向右"):
        自身.position.x += 200 * delta
    结束
结束
```

支持事件：`游戏开始` → `_ready`、`每帧(delta)` → `_process(delta)`、`物理帧(delta)` → `_physics_process(delta)`、`输入事件(事件)` → `_input(event)`、`退出场景` → `_exit_tree`。

## 运行流程

1. C++ 编译器进行 UTF-8 词法处理与中文语法转换。
2. 编辑器插件根据选中节点的 Godot 原生类型生成 `extends <NodeClass>`。
3. 创建 GDScript 并调用 Godot 的脚本检查。
4. 检查通过后通过 EditorUndoRedoManager 将脚本绑定到选中节点。
5. 保存场景后，游戏运行时由 Godot 调用生命周期事件。

## 中文 API 第一批

`自身`、`输入`、`获取节点`、`获取节点或空`、`位置`、`旋转`、`缩放`、`可见`、`名称`、`正在按下`、`移动并滑动`。

## 后续路线

- 完整 AST、表达式优先级、错误行列定位。
- 节点树、信号、动画、物理、UI、资源和场景操作 API。
- 类型推导、作用域、模块、调试映射、断点和热重载。
- 在稳定兼容层之上评估独立字节码运行时。
